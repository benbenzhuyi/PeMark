# PeMark

**Direct-PE Markdown Editor**

[简体中文](README.zh-CN.md) | English

PeMark is a native Windows x64 Markdown editor whose executable is generated
directly from Python as a PE32+ image and AMD64 machine-code bytes. The
production executable uses no compiler, assembler, linker, managed compiler,
interpreter packager, or embedded Python runtime.

> **V8.6.3** is the current stable release. It retains the V8.5.4 document
> safety, dynamic-capacity and permission-separated PE baseline, and completes
> the V8.6 desktop workspace, custom title row, large-document Preview fixes and
> high-DPI text rendering work.

## Highlights

- Native Win32 x64 GUI executable with a compact custom title/menu row.
- Source and formatted Preview modes with position mapping.
- Markdown headings, emphasis, inline code, fenced code, quotes, lists and links.
- Outline navigation generated by the same scan as Preview rendering.
- Expandable workspace tree with Fluent folder/document glyphs, keyboard
  navigation, inline rename, New File/New Folder, Recycle Bin delete, Copy Path,
  Refresh and Collapse All.
- Light and dark themes, zoom, word wrap, find and replace.
- GDI-scaled DPI awareness for sharp RichEdit, menu and sidebar text on scaled
  displays.
- Deterministic Direct-PE build with six permission-separated PE sections,
  ASLR and no writable-and-executable section.

## Download

Download `pemark_x64_v8_6_3.exe` from the
[PeMark V8.6.3 release](https://github.com/benbenzhuyi/PeMark/releases/tag/v8.6.3).

Expected SHA-256:

```text
6b26585bb453010e358c726931d96f43cf5c4ef27cd02d1aff6101ad378698df
```

The executable is unsigned, so Windows SmartScreen or security products may
show a warning. Verify the hash before running it.

## Requirements

Runtime:

- 64-bit Windows 10 or Windows 11.
- The Windows Rich Edit implementation supplied by `msftedit.dll`.

Build and deterministic tests:

- Python 3.10 or later.
- `unicorn` for emitted-machine-code regression tests.

```powershell
python -m pip install -r requirements-dev.txt
```

## Build

From the repository root:

```powershell
python .\src\current\generate_markdown_editor_v8_6_3.py
```

The generator writes `bin/current/pemark_x64_v8_6_3.exe` without invoking a
native compiler, assembler or linker.

## Verify

```powershell
python .\tools\build_current.py
python .\tools\test_v8_5_1.py .\src\current\generate_markdown_editor_v8_6_3.py
python .\tools\inspect_pe.py .\bin\current\pemark_x64_v8_6_3.exe
python .\tools\smoke_test_v8_5_1.py .\bin\current\pemark_x64_v8_6_3.exe
Get-FileHash -Algorithm SHA256 .\bin\current\pemark_x64_v8_6_3.exe
```

The smoke test controls the real GUI and must run in an interactive Windows
desktop session.

Release evidence includes:

- two consecutive builds with the expected SHA-256;
- 13/13 emitted-x64 behavior groups and 210/210 scrollbar geometry cases;
- 17/17 Windows GUI smoke checks and 5/5 clean exits;
- Open/encoding, atomic-save, destructive-transition and arena-failure suites;
- real-process coverage for the workspace tree, file operations, keyboard
  navigation, custom caption, themes and DPI mode;
- six PE sections with RX/R/RW/RW/R/R permissions and no W+X page.

## Known limitations

- The executable is unsigned.
- The Settings gear and right-sidebar switch are visual placeholders.
- Full stack walking beyond the first PeMark frame remains unproven, although
  the unwind table is valid and resolvable and PeMark does not use exceptions.
- AI integration and advanced editing beyond the current desktop workspace are
  outside this release.

Keep an independent copy of important documents.
