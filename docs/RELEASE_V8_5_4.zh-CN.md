# PeMark V8.5.4

[English](RELEASE_V8_5_4.md) | 简体中文

V8.5.4 是 PeMark 的首个稳定版。Python 生成器仍然直接写出 PE32+ 映像与 AMD64
机器码，不使用编译器、汇编器或链接器；这个版本的意义在于：用户真正依赖的那些
性质，已经从"设计意图"变成"有测量证据"。

## 这里的"稳定"指什么

- 工作成果受保护：保存通过同级暂存文件与原子替换完成；未保存状态由文档
  revision 推导，并由统一的保存/放弃/取消控制器保护；所有已测试的失败路径都会
  保留原文件与内存中的文档。
- 不再静默截断：document、render、样式、大纲、解码与文件字节的固定缓冲区全部
  退役，改为按实际文档规模分配的 arena；分配失败不会改变当前文档。
- 内存有据可查：虚拟 BSS 从 119.5 MB 降到 8 KB，重复打开/解析/关闭后内存与
  句柄达到稳定平台。
- 映像已加固：六个节权限分离（不存在同时可写且可执行的页），启用基址重定位与
  ASLR，并为全部非叶例程生成栈回溯元数据。

## 相对 V8.5.1 Preview 的累积变化

| 方面 | V8.5.1 Preview | V8.5.4 |
|---|---|---|
| 保存 | 单次 `CREATE_ALWAYS` 写入，接受短写 | 暂存文件 + 完整写入循环 + 原子替换 + 恢复政策 |
| 未保存内容 | 无保护 | revision 推导的脏状态 + 统一保存/放弃/取消 |
| 编码 | UTF-8，畸形时静默回退 ANSI | 严格 UTF-8 / UTF-8 BOM / UTF-16LE BOM，保留换行 |
| 容量 | 大纲 2048、样式 131072、8.5M 单元固定缓冲 | 动态 arena，无静默截断 |
| 内存 | 119.5 MB 虚拟 BSS | 8 KB 虚拟 BSS，稳定平台 |
| PE | 单一可读可写可执行节，固定基址 | 六节、强制 W^X、ASLR、`.pdata` |

## 验证

- 13/13 组机器码行为测试，含 210/210 组滚动条边界组合；
- 17/17 项 Windows GUI 冒烟检查与 5/5 次干净退出；
- 打开/编码事务矩阵与八种原子保存故障模式；
- 破坏性转换与 revision 归属矩阵；
- Outline、样式、渲染、document、解码与文件字节 arena 的分配失败注入；
- 2600 标题、140000 跨度与 1.2 MB 文档容量用例；
- 12 轮"打开 + 预览 + 新建"内存平台测量，句柄零增长；
- 节权限与 ASLR 在**已加载映像**上验证，而不只是检查文件；
- 连续构建结果一致；独立机器可用 `tools/verify_release_v8_5_4.py` 复现同一覆盖。

## 已知限制

- EXE 未签名。Windows SmartScreen 可能提示；运行前请核对上面的 SHA-256。
- 4 MiB 输入政策仍是编译期上界；超限文件会被显式拒绝而不是截断，其背后的
  缓冲区已是动态的。
- 旧代码页不再作为回退，非 UTF-8/UTF-16 文档需要先转换。
- **完整跨帧栈回溯尚未证明**：`.pdata` 结构正确、系统能为我们的地址解析条目、
  回溯能到达本模块，但调试器未从我们的第一帧继续向上。代码不使用异常，行为
  不受影响。
- 验证在维护者机器与一台独立机器上完成；更广泛的环境覆盖仍在推进。
- 工作区、高级编辑与 AI 功能不在本版本内。
