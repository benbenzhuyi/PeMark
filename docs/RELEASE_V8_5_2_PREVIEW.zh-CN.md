# PeMark V8.5.2 Preview

[English](RELEASE_V8_5_2_PREVIEW.md) | 简体中文

V8.5.2 是文档安全版本，继续保持纯 Direct-PE 构建：Python 直接写出 PE32+ 映像
与 AMD64 指令，不使用编译器、汇编器或链接器。以下安全保证没有以行为降级为代价。

## 新增

- 64 位 `document_revision` 与 `saved_revision`。未保存状态只由 revision 是否
  相等推导，不存在独立的 dirty 标志。
- 新建、打开、退出和关闭窗口共用一个未保存内容控制器，提供保存/放弃/取消。
  保存失败等同取消，文档保持不变。
- Save As 事务化：选定的路径在写入成功并关闭句柄之前只是候选路径。

## 修复

- 保存改为先写同级 `.pemark.tmp` 暂存文件，循环写完整个快照，刷新缓冲区，
  检查关闭结果，再用 `MoveFileExW(REPLACE_EXISTING | WRITE_THROUGH)` 提交。
  所有已测试的提交前失败都保留原文件；已存在的暂存文件会被保留并给出提示，
  不会被截断覆盖。
- 原先的单次 `WriteFile` 可能静默接受短写。现在部分写入会推进缓冲区指针，
  API 失败、零进展或计数超过请求量都会判定保存失败。
- 打开文件原先会在确认新文档可读之前就改变视图、路径和模型状态。现在读取、
  解码和两次 arena 预留全部完成后才进入唯一提交点；失败时文本、路径、
  revision、编码、换行偏好和视图模式都保持不变。
- 打开原先只读一次并接受读到的内容，现在会循环读到文件大小快照完全满足，
  并拒绝零进展。
- 畸形 UTF-8 原先会静默回退到 ANSI 代码页。现在 UTF-8、UTF-8 BOM 与
  UTF-16LE BOM 都是显式严格路径；畸形 UTF-8、内嵌 NUL 和奇数长度 UTF-16
  一律拒绝。
- 编码与首选换行随文档一起提交，保存时保留 UTF-8、UTF-8 BOM 或 UTF-16LE BOM，
  以及 CRLF、LF 或 CR。

## 容量

- 2048 项 Outline 上限与 131072 项 Markdown 样式上限均已退役。两张表现在位于
  `VirtualAlloc` arena 中，容量由归一化文档长度推导，并在打开提交点之前预留。
- 140000 个跨度的文档可以完整记录；旧版本会在 131072 处截断。

其余动态容量工作（document、render、position-map 与编码输出缓冲区）顺延为
V8.5.3。

## 验证

- 13/13 组机器码行为测试，含 210/210 组滚动条边界组合。
- 17/17 项 Windows GUI 冒烟检查。
- 5/5 次普通关闭均返回退出码 0。
- 打开事务与严格编码矩阵：UTF-8、UTF-8 BOM、UTF-16LE BOM、LF、CRLF、CR
  往返（含空 BOM 文件）；畸形输入保持原文档。
- 原子保存故障注入：短写补齐、零进展拒绝、首次失败、部分后失败、刷新失败、
  替换失败、暂存文件创建失败、关闭失败后清理重试。
- 破坏性转换矩阵：干净关闭；脏关闭与新建的取消/放弃/保存；打开决策取消与
  文件选择取消；关闭时保存失败。
- Outline 与样式表的分配失败注入。
- 连续两次构建得到完全相同的二进制。

## 预览版限制

document、render、position-map 和编码输出缓冲区仍是固定大小，超大输入会被
显式拒绝而不是截断。旧代码页不再作为回退，非 UTF-8/UTF-16 文档需要先转换。
代码签名、ASLR 与 PE 权限分节尚未实现，长时间运行的内存平台测量尚未完成，
工作区与 AI 功能不在本版本内。请为重要文档保留备份。
