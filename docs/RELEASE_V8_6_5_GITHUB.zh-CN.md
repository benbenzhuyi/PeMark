# PeMark V8.6.5

[English](RELEASE_V8_6_5_GITHUB.md) | 简体中文

纯 Direct-PE Markdown 编辑器的稳定版发布。整个构建不涉及编译器、汇编器、
链接器、托管运行时或解释器打包器：由 Python 生成器直接产出 PE32+ 镜像与
AMD64 机器码。

## 亮点

**窗口在两种主题下都有了可见边框。** 两个相互独立的原因都在运行窗口上实测
确认并已修复：

1. `WM_NCCALCSIZE` 让客户区覆盖整个窗口，DWM 根本没有可绘制的边框条；
2. `DWMWA_BORDER_COLOR` 被设成了窗口背景本身（深色 `#202020` 底上用的是
   `#1A1A1A`，浅色底用的是纯白），因此即便画了边框也看不见。

现在的边框色取自对 Windows 资源管理器边框的逐像素测量：深色 `#3C3C3C`、
浅色 `#B0B0B0`，150% 显示缩放下宽 2 个物理像素——与资源管理器的亮度和粗细
一致。

## 改动内容

- `wp_nccalcsize` 把返回的客户区矩形四边各内缩 1px，恢复 DWM 绘制边框所需的
  那条 1px 非客户区。子控件相对客户区定位，因此自动内移 1 像素，布局代码一行
  未改。
- `DWMWA_BORDER_COLOR` 随主题取值，绝不与窗口背景同色。
- `wp_ncpaint` 不再用 GDI 绘制四边。实测表明 DWM 会把它的边框合成在任何落在
  这些像素上的 GDI 绘制之上，两者并存会产生四条颜色各异的边。

## 验证

- 连续两次构建得到完全相同的二进制摘要；
- 机器码回归：`failures: []`（含 210 组滚动条几何组合、裁剪与格式化不变量、
  拖拽夹紧、退出路径）；
- PE 检查：6 个段，RX/R/RW/RW/R/R，无 W+X 页；
- 交互式桌面 GUI 冒烟：17/17 通过，退出码 0；
- 边框像素实测：四边统一为浅色 `#B0B0B0` / 深色 `#3C3C3C`，切换主题时在一帧
  内同步更新。
