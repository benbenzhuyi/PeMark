# PeMark · 码记 V8.5.1 Preview

[English](RELEASE_V8_5_1_PREVIEW.md) | 简体中文

V8.5.1 建立了首个可公开发布的 V8.5 基线，并保持纯 Direct-PE 构建：
Python 直接生成 PE32+ 映像和 AMD64 指令，不使用编译器、汇编器或链接器。

## 已修复

- 主窗口销毁后的确定性正常退出；
- 由单一 ViewState 写者维护正确的源码/预览可见性；
- 统一生成预览、样式、位置映射和大纲的扫描器；
- 围栏代码块缩进和空格无损保留；
- 提高文本上限后再安全重建自动换行 EDIT；
- 大文档 Markdown 样式限制在实际视口范围；
- 绘制、命中测试和拖动共享缓存滚动条几何。

## 验证

- 12/12 组机器码行为测试通过；
- 210/210 组滚动条边界组合通过；
- 17/17 项 Windows GUI 冒烟检查通过；
- 5/5 次普通关闭返回退出码 0；
- 连续构建得到完全相同的二进制。
