# PeMark V8.5.3 Preview

[English](RELEASE_V8_5_3_PREVIEW.md) | 简体中文

V8.5.3 是动态容量版本。它继续保持纯 Direct-PE 构建，保留 V8.5.2 的全部文档
安全保证，并移除了最后一批按文档规模固定的缓冲区。可见行为没有降级：4 MiB
输入政策、编辑器文本上限和未保存内容规则都保持不变。

## 变更内容

- document 文本、位置映射与渲染文本、样式跨度和大纲表现在都位于按实际文档
  规模分配的 arena 中，2048 项大纲上限与 131072 项样式上限已经退役。
- 解码/序列化 scratch 与文件字节缓冲区改为按操作规模以 64 KiB 块提交，编码
  API 的上限改为读取已发布容量。小文档不再预留只有大文档才需要的内存。
- 每个 arena 只在分配成功后才发布指针，因此增长失败不会改变当前文档、路径、
  revision、编码与换行元数据。已经提交的容量作为可复用缓存保留。

## 容量结果

| 缓冲区 | V8.5.2 | V8.5.3 |
|---|---|---|
| 虚拟 BSS | 119,508,992 字节 | 8,192 字节 |
| PE 虚拟尺寸 | 121,159,680 字节 | 86,016 字节 |
| 大纲条目 | 固定 2048 | 动态 |
| 样式跨度 | 固定 131072 | 动态 |
| document、render、解码与文件缓冲 | 固定 | 动态 |

阻碍 PE 分节的巨大可写区域已经消失，PE 硬化顺延到 V8.5.4。

## 验证

- 13/13 组机器码行为测试；
- 17/17 项 Windows GUI 冒烟检查；
- 5/5 次普通关闭返回退出码 0；
- 打开/编码事务矩阵与八种原子保存故障注入；
- 破坏性转换与 revision 归属矩阵；
- Outline、样式、渲染、document、解码与文件字节 arena 的分配失败注入；
- 2600 标题大纲、140000 跨度样式与 1.2 MB 文档容量用例；
- 内存平台：小/中/大文档各 12 轮"打开 + 预览 + 新建"，句柄零增长，私有内存
  增长约 1.8 MB；
- 连续两次构建得到完全相同的二进制。

## 预览版限制

4 MiB 输入政策仍是编译期上界，虽然其背后的缓冲区已经动态化；放宽该政策属于
独立且需单独验证的变更。旧代码页仍不作为回退。映像仍是单一可读可写可执行节，
未签名，也没有 ASLR 与 unwind 元数据。工作区、高级编辑与 AI 功能不在本版本内。
请为重要文档保留备份。
